# Coco Bottom app pages

Public privacy, terms, and support pages for every application published by
Coco Bottom. Served by GitHub Pages from the repository root.

One page set per application, in a directory named after the application.
Adding an application means adding a directory and a section in `index.html`.

The source of truth for each page's wording lives with its application, in
`apps/<app>/public/`. Copy changes here after they are agreed there.

Support contact for all applications: cocobottom2012@gmail.com
